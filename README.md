# Thaali - The Digital Restaurant API 🍽️

**Backend Developer | Thaali - The Digital Restaurant API**  
A scalable and secure RESTful API built for modern restaurant management—powering billing, ordering, reviews, and more.

## 🚀 Features

- 🔐 **Authentication**

  - JWT and OAuth-based secure login system
  - Role-based access control for customers and admins

- 📦 **Restaurant Operations**

  - Menu and order management
  - Real-time billing and invoice generation
  - Customer reviews and rating system

- 🗃️ **Database Design**
  - Efficient and normalized PostgreSQL schema
  - Optimized queries for fast data retrieval

## 🛠 Tech Stack

- **Backend Framework:** Node.js, Express.js
- **Authentication:** JWT, OAuth
- **Database:** PostgreSQL
- **API Testing:** Postman

## 📁 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/AnishCodeth/thaali_the-untold.git
   cd thaali_the-untold
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up environment variables**  
   Create a `.env` file and configure the following:

   ```env
   PORT=3000
   DATABASE_URL=your_postgresql_database_url
   JWT_SECRET=your_jwt_secret
   ```

4. **Run the server**
   ```bash
   npm start
   ```
